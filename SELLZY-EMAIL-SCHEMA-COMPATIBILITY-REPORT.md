## 1. Executive Summary

We have enforced a single, shared, canonical column definition between the **Email Grabber export engine** and the **Email Sender import/matching engine** across the Sellzy SaaS platform (`D:\projects\ecommerce-machine`).

Grabber exports and Sender imports are now **100% seamlessly round-trip compatible**. An export generated by the Email Grabber can be imported directly into the Email Sender with **zero manual column mapping**, with strict header validation, formula injection protection, and guaranteed zero-send safety.

---

## 2. Shared Canonical Schema Definition

The canonical schema is centralized in `@sellzy/shared` (`packages/shared/src/index.ts`) as `CANONICAL_LEAD_HEADERS`:

| Column Position | Exact Header Name | Data Type | Notes / Validation |
| :---: | :--- | :--- | :--- |
| **1** | `Email` | String (Required) | RFC 5322 compliant email address |
| **2** | `First Name` | String (Optional) | Preserved if provided; empty if uncollected |
| **3** | `Last Name` | String (Optional) | Preserved if provided; empty if uncollected |
| **4** | `Company` | String (Optional) | Registered business name |
| **5** | `Website` | String (Optional) | Validated company domain/URL |
| **6** | `Industry` | String (Optional) | Business category or vertical |
| **7** | `Country` | String (Optional) | Default: `US` |
| **8** | `State` | String (Optional) | 2-letter state code or name |
| **9** | `City` | String (Optional) | Municipal jurisdiction |
| **10** | `Source URL` | String (Optional) | Authoritative public directory listing URL |
| **11** | `Verification Status` | String (Optional) | Deliverability status (`deliverable`, `unverified`, etc.) |

## 3. Before vs. After Comparison

### Before
- **Email Grabber Export Headers:**
  `['Company Name', 'Email', 'Website', 'Phone', 'City', 'State', 'Country', 'Industry', 'Verification Status', 'Collected At', 'Source']` (11 columns in non-standard order; `Company Name` first).
- **Email Sender Expected Mapping:**
  Required manual mapping of arbitrary keys `{ email, companyName, website, ... }`. If headers differed, manual mapping was required.
- **Header Order:** Out-of-order exports failed direct automated ingestion without manual user mapping.

### After
- **Unified Canonical Headers:**
  Both modules exclusively use `CANONICAL_LEAD_HEADERS` (`Email`, `First Name`, `Last Name`, `Company`, `Website`, `Industry`, `Country`, `State`, `City`, `Source URL`, `Verification Status`).
- **Direct Zero-Friction Ingestion:**
  The Sender automatically recognizes canonical exports and executes matching immediately without requiring manual column selection.
- **Strict Ordering & Validation:**
  `SpreadsheetParserService.validateHeadersAgainstCanonical()` checks missing headers, extra headers, and order mismatches.
